PulseUSB
USB driver needed
Windows needs the free usbip-win2 driver to show remote devices as plugged in. This downloads and installs it; Windows will ask for permission once.
Starting at boot needs to be set up again
PulseUSB was updated, moved or reinstalled since "At boot, before sign-in" was switched on, so Windows is no longer starting it before you sign in. Setting it up again asks for administrator permission once.

Running as a system service
PulseUSB starts with this computer and keeps auto-connect devices connected, whether or not this window is open. Manage it with "systemctl status pulseusb".

Disconnect everything
Shortcuts work anywhere in Windows, also with this window closed. Each group can have its own: set it with the ⌨ button on the group.

Keyboard and mouse stuck on another computer?

If the keyboard and mouse you share are in use on another computer, press Ctrl+Alt+Shift+F12 on that keyboard. The server takes every device back for the machine it is plugged into. Press the same keys there to share them again, or use Take over here. (Needs the server from PulseUSB 0.23 or later.)
